# ESG-Portfolio-Optimizer


# Overview
This project explores the integration of Environmental, Social and Governance (ESG) criteria into portfolio construction and investment analysis.
The objective is to develop a reproducible Python-based framework for collecting, analyzing and visualizing ESG and financial data in order to compare responsible investment strategies with traditional portfolio approaches.

*Work in progress*.


# Objectives

- Explore the role of ESG criteria in portfolio construction.
- Compare financial and sustainability characteristics of different portfolios.
  (Is sustainability correlated with profitability ?)
- Strengthen skills in financial data analysis, ESG datasets and Python development.


# ESG dataset
From Kaggle : Public Company ESG Ratings Dataset
ESG ratings for over 700 mid / large-cap companies across various industries
